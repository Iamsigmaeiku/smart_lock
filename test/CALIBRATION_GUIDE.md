# 觸控校準指南

## 目的

調整 `config.h` 中的觸控校準參數，確保觸摸準確對應螢幕位置。

## 校準步驟

### 1. 準備校準程式

```bash
# 備份原main.cpp
cp src/main.cpp src/main.cpp.backup

# 複製校準測試程式
cp test/touch_calibration_test.cpp src/main.cpp
```

### 2. 編譯並上傳

```bash
pio run -t upload
pio device monitor
```

### 3. 執行校準

螢幕會顯示5個標記點：

- 🔴 左上角 (10, 30)
- 🟢 右上角 (310, 30)
- 🔵 左下角 (10, 230)
- 🟡 右下角 (310, 230)
- ⚪ 中心 (160, 120)

**依序觸摸每個標記點**，記錄序列埠輸出的**原始座標**。

### 4. 記錄數據

建立一個表格記錄：

| 位置 | 目標座標 | 原始 X | 原始 Y |
|------|---------|--------|--------|
| 左上 | (10, 30) | ??? | ??? |
| 右上 | (310, 30) | ??? | ??? |
| 左下 | (10, 230) | ??? | ??? |
| 右下 | (310, 230) | ??? | ??? |
| 中心 | (160, 120) | ??? | ??? |

### 5. 計算校準參數

根據記錄的數據計算：

```
TS_MINX = min(左上X, 左下X) - 100
TS_MAXX = max(右上X, 右下X) + 100
TS_MINY = min(左上Y, 右上Y) - 100
TS_MAXY = max(左下Y, 右下Y) + 100
```

### 6. 更新 config.h

修改 `include/config.h`：

```cpp
// 觸控校準參數（需根據實際硬體調整）
#define TS_MINX 你計算的值
#define TS_MAXX 你計算的值
#define TS_MINY 你計算的值
#define TS_MAXY 你計算的值
```

### 7. 重新測試

重複步驟 2-3，檢查映射座標是否準確。觸摸標記點時，映射座標應該接近目標座標（誤差 ±5 像素可接受）。

### 8. 恢復主程式

校準完成後：

```bash
# 恢復原main.cpp
cp src/main.cpp.backup src/main.cpp

# 重新編譯上傳
pio run -t upload
```

## 範例

假設你測試的結果是：

| 位置 | 原始 X | 原始 Y |
|------|--------|--------|
| 左上 | 350 | 450 |
| 右上 | 3750 | 400 |
| 左下 | 380 | 3700 |
| 右下 | 3800 | 3750 |

計算參數：

```
TS_MINX = min(350, 380) - 100 = 250
TS_MAXX = max(3750, 3800) + 100 = 3900
TS_MINY = min(450, 400) - 100 = 300
TS_MAXY = max(3700, 3750) + 100 = 3850
```

## 故障排除

### 觸摸無反應

1. 檢查 `TOUCH_CS` 和 `TOUCH_IRQ` 接腳是否正確
2. 檢查觸控排線是否插好
3. 確認觸控控制器型號（XPT2046 或 FT6206）

### 座標偏移嚴重

1. 檢查 `tft.setRotation()` 和 `touch.setRotation()` 是否一致
2. 重新校準，擴大參數範圍

### 觸摸點跳動

1. 降低觸摸靈敏度
2. 添加軟體濾波（移動平均）
3. 增加防抖延遲

## 進階調整

如果標準校準仍不準確，可能需要：

1. **非線性校準**：使用多點校準和插值
2. **旋轉補償**：如果觸控和螢幕旋轉不匹配
3. **交換XY軸**：某些硬體需要交換座標軸

參考 XPT2046_Touchscreen 庫文檔獲取更多選項。
